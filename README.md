# JobTrack – Job Application Tracker 💼

A simple job application management system built using Python and Streamlit.

## Features

- Add new job applications
- View all applications
- Search applications by company name
- Filter applications by status
- Update application status
- Delete applications
- Dynamic dashboard statistics
- Application status breakdown chart
- Recent applications overview
- Dark-themed interactive interface

## Tech Stack

- Python
- Streamlit
- Object-Oriented Programming
- Git and GitHub


## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/job-application-tracker.git
```

2. Navigate to the project directory:

```bash
cd job-application-tracker
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```

## Note

Application data is currently stored in session memory and is not permanently saved after the application session ends.
